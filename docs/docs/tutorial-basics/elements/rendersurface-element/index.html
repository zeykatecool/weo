RenderSurface Element

RenderSurface is a module that provides a drawing surface for custom rendering.
It supports text rendering, mouse interaction, and redraw handling.

RenderSurface Element
Element
LuaRT Element
​

Constructor​

RenderSurface.new()
Function
​

RenderSurface.new(RenderSurfaceProperties)​

  • Creates a new RenderSurface element,actually a Canvas object.

You can just create your RenderSurface with bgcolor and visible properties. Other properties will be set to default values. If you want more than one RenderSurface, remember you may need to set the zIndex manually,also align,size and position properties.

Parameters:

  • IsRenderSurface

    true

    • READONLY: Used internally by Weo for parent checking.

  • RenderElements

    table

    • READONLY: Managed internally by Weo.

  • parent

    Window

    • READONLY: Parent window of the RenderSurface. Mostly it's a Window.

  • x

    number?

    • Horizontal position of the RenderSurface.

  • y

    number?

    • Vertical position of the RenderSurface.

  • width

    number?

    • Width of the RenderSurface.

  • height

    number?

    • Height of the RenderSurface.

  • align

    string?

    • Alignment relative to parent. Automatically set to "all" by Weo.

  • enabled

    boolean?

    • Whether the RenderSurface responds to input.

  • visible

    boolean?

    • Controls visibility of the RenderSurface.

  • color

    string?

    • Current drawing color.

  • bgcolor

    number?
    LinearGradient?
    RadialGradient?

    • Background color of the RenderSurface.

  • font

    string?

    • Current font (from Windows system fonts).

  • fontsize

    number?

    • Font size.

  • fontweight

    number?

    • Font weight (1–999).

  • fontstretch

    number?

    • Font stretch (1–9).

  • fontstyle

    Enum.FontStyle?

    • Font style.

  • window

    Window

    • The window to which the RenderSurface is attached.

  • cursor

    Enum.CursorStyle?

    • The cursor to display when the mouse is over the RenderSurface.

Weo uses this property to set the cursor when the mouse is over the other elements,like Button.

(RenderSurface):Refresh()
Method
​

(RenderSurface):Refresh(force)​

  • Forces redraw of the RenderSurface.

This is for a bug in LuaRT 2.0.1 x64. After hiding (Window) and showing it again, the RenderSurface will not be redrawn.
This method calls (RenderSurface):onPaint() to redraw via UpdateService,performance is not guaranteed.

Parameters:

  • force
    boolean

Example​

-- Creating a RenderSurface
local Render = RenderSurface.new(window, {
    bgcolor = Color.fromHEX("#7E0202FF"),
    visible = true,
})

-- Creating a Frame,which renders on the RenderSurface
local MyFrame = Frame.new(Render, {
    position = UDim2.new(0, 300, 0, 300),
    size = UDim2.new(0, 100, 0, 100),
    bgcolor = Color.fromHEX("#1593CEFF"),
    visible = true,
    borderRadius = 15,
    zIndex = 0,
})

Notes​

  • See LuaRT Canvas Documentation for details.
  • RenderSurface stops updating :onPaint() after the window hidden and shown again. It's a known bug in LuaRT 2.0.1 x64 and not an issue of Weo.
    • You can force (RenderSurface):Refresh(force : boolean) to update RenderSurface with UpdateService.Heartbeat, but performance is not guaranteed since this is a workaround for the issue.
