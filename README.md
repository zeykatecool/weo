# Getting Started with Weo
Weo is a extension for LuaRT, designed to unlock its full potential.

Please visit *https://zeykatecool.github.io/weo/* for documentation.

## Project Status

This project is still very young.  
Core systems such as window handling, tweening, and positioning are implemented and functional.  

However, the library has **not been extensively tested** and its **usability is still limited**.  
Expect frequent changes and evolving features as development continues.


## Installing
### Git

```sh
git clone https://github.com/zeykatecool/weo.git
cd Weo
```

## Weo CLI
It's planned to be a command-line interface for Weo but it's not ready yet.
